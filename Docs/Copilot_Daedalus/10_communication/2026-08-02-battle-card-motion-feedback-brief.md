# BattleScene 出牌聚焦与弃牌过渡需求说明

> 用途：把 M6C 人工审阅发现的表现问题交给后续 M9 实现者或美术协作者。本文不授权在 M6 中实现 Effect、最终动画或改变权威卡区规则。

## 1. 已有功能基线（不要重做）

- M6 的 Enemy 牌越过出牌线后会进入目标选择：卡牌位置冻结，功能性箭头跟随指针，合法/悬停目标高亮，并只向 `BattleCommandQueue.Submit` 提交精确 `TargetId`。
- Self 牌越线时直接选择玩家自身；空白、玩家、死亡或非法目标释放不会提交，卡牌回弹。
- 费用不足时费用显示不可支付颜色；M6C 修订后仍允许拿起和拖动，但不会进入出牌反馈、目标选择或提交。
- `EndPlayerActionCommand` 会按 M2/M4 的权威规则把剩余手牌移入弃牌堆。后续表现只能观察这次事实变化，不能继续展示一份冒充手牌事实的旧列表。

## 2. M9 出牌聚焦表现

人工审阅认为 Enemy 卡越线后原地冻结会遮挡视野且显得僵硬。M9 应在不改变 M6 目标语义的前提下增加可配置的聚焦过渡：

1. 首次越过出牌线后，把卡牌从当前拖拽位置缓动到一个可配置的“目标选择聚焦锚点”；建议位于屏幕下方中央、手牌上缘与战场之间，不能遮住主要敌人或 HUD。
2. 聚焦时把卡牌旋转平滑归零，并使用小幅缩放/悬浮呼吸表现；箭头起点随聚焦卡牌更新，终点继续严格跟随物理指针。
3. 进入聚焦后的命中、合法高亮、释放与 `TargetId` 提交仍复用 M6 seam；不得把 DOTween 回调变成权威出牌入口。
4. 无效释放、阶段变化、队首失败或对象销毁必须取消 Tween、箭头与高亮，并回到现有安全恢复路径。
5. 聚焦锚点、时长、缓动和缩放应通过 Prefab/序列化参数配置，不在规则模块中保存表现状态。

参考作品只能用于理解“信息清晰、卡牌不遮挡战场”的体验目标；不得复刻《杀戮尖塔 2》或其他作品的具体资产、曲线、构图与动画。

## 3. M9 结束行动弃牌表现

人工审阅观察到进入 `EnemyAction` 后剩余手牌立即消失。当前权威结果是正确的：结束行动时剩余牌已经进入弃牌堆。M9 应补充从事实变化到 View 销毁之间的可见过渡，而不是延迟或伪造权威卡区：

1. 捕获权威命令前后的卡牌实例 ID 差异，让本次从手牌进入弃牌堆的 View 依次/成组飞向弃牌堆 HUD。
2. 过渡期间卡牌只作为非交互表现对象存在；不能再次提交、改变能量或被目标选择系统命中。
3. 过渡结束后销毁旧 View，并以当前 `BattleCardZonesData` 重建/刷新手牌；进入下一轮仍由现有抽牌规则恢复新手牌。
4. 阶段中断、场景销毁或动画取消必须立即清理残留 View、箭头、高亮和 Tween。

## 5. 后期验收口径

- 16:7、16:9、16:10、16:11、16:14 中聚焦卡牌均不遮挡主要敌人，箭头端点与目标矩形对齐。
- Enemy 卡选目标时精确命中左右敌人；空白/玩家/非法目标仍零提交并安全回弹。
- 费用不足卡仍可拖动，但不显示箭头/目标高亮、不提交，释放后回弹且权威事实不变。
- 结束行动后剩余牌有清晰的弃牌过渡；`EnemyAction` 中没有可交互的旧手牌，也没有权威手牌的镜像状态。
- 动画取消、切场景、下一轮恢复后无残留卡牌、箭头、高亮或 Tween；Console 无 Error。
- M7 Effect 执行器产生的伤害/格挡/状态反馈另行验收，不能用本动画需求代替。

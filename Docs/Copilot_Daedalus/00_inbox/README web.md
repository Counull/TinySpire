# 🎖 机枪兵 · 类杀戮尖塔卡牌游戏

> 单人肉鸽卡牌游戏 · 浏览器直接运行 · 数据驱动引擎

## 📦 如何运行

双击打开 **`battle.html`** 即可游玩（无需任何服务器/依赖）。推荐 Chrome / Edge 打开。

| 文件 | 说明 |
|---|---|
| `battle.html` | 完整游戏（引擎 + 内嵌数据），双击即玩 |
| `cards.json` | 数据源（卡牌/敌人/地图/buff/升级），与 HTML 内嵌同步 |
| `README.md` | 本设计文档 |
| `test/` | AI 自动化测试（`gen-test.ps1`，Edge 无头运行） |

> ⚠️ 浏览器 file:// 协议下无法 fetch 外部 JSON，所以数据在 `battle.html` 内嵌了一份 + `cards.json` 外部一份，改数据需同步两处。

## 🎮 核心玩法

**机枪兵**对抗敌方防线，一路推进 15 层击败 BOSS。每局随机生成地图路线，战斗获得新卡，篝火休息/升级，问号房间触发随机事件。

### 玩家基础

| 属性 | 规则 |
|---|---|
| 生命 | 70，跨战斗**继承不补满**，阵亡整局重开 |
| 能量 | 上限 5，每回合 +3，**跨回合保留不清零** |
| 弹药 | 上限 5，开局满，每回合 +1，**跨回合保留不清零**（射击资源） |
| 抽牌 | 每回合抽 5；手牌上限 **10 张** |
| 格挡 | 本回合阻挡伤害，**回合开始清零**（玩家/敌人同规则） |

### 伤害管线（全局结算顺序）

```
虚弱(攻击者 -25%) → 烟雾(攻击者&受击者各每层-1) → 易伤(受击者 +50%) → 格挡 → 生命
```

- **力量体系**：力量 + 临时力量 − 失去力量（下限 0），由 attackDamage 单次结算
- 燃烧等 debuff 伤害**不经过此管线**（只过格挡或直接扣血）
- **延迟伤害**：只过格挡（逐段独立消耗）、**不吃**攻击方力量/虚弱、**受**受击方烟雾减免。**支援类**（火力支援/女妖战机/燃烧轰炸/三连击延迟狙击）**吃受击方易伤**（×1.5）；**炸弹**延迟伤害仍不吃易伤
- **烟雾豁免**：debuff 伤害（燃烧结算、不充分爆燃燃烧波）不受烟雾干扰
- **隐身**：玩家受到的伤害减半（含延迟伤害与燃烧）
- 意图面板显示**结算后的有效伤害**

### 回合结束结算顺序（玩家）

```
弃牌 → 清束缚/失去力量/临时力量/临时敏捷 → 恢复(先回血) → 炸弹(先伤敌) → 燃烧(对玩家造成伤害的debuff最后结算) → 敌人行动
```

> 恢复**始终优先于燃烧**；对玩家造成伤害的 debuff（燃烧）**永远最后结算**——先结算炸弹等伤敌效果，避免燃烧把玩家烧死时吞掉本回合的炸弹引爆。

| **无实体** | 玩家 | 受到的攻击伤害降为 1；被攻击后 -1 层（mod 新增，防御靶机） | 不随回合衰减，可叠加 |

**设计原则**：燃烧 = 可阻挡持续伤害；未来**毒素** = 不可阻挡的另一体系。怪物不会给玩家上无法阻挡的掉血 buff。

**敏捷/格挡边界**：敏捷+临时敏捷使格挡净值 ≤0 时，本次获得 0 格挡（不扣已有格挡）。

**射击分类**（`isShoot`）：射击词条 / 狙击词条 / 霰弹词条（占位）——所有「非射击类判定」（连肘免费条件等）统一排除整个分类。
- **射击词条**（`shoot:true`）：吃兴奋剂（额外1弹）、燃烧弹药（命中上燃）、开火（每段+伤害）
- **狙击词条**（`sniper:true`）：不吃兴奋剂；吃燃烧弹药；对易伤或隐身中的敌人造成×2伤害；**不吃自身烟雾减输出，只吃敌人身上烟雾减伤**
- **霰弹词条**（`shotgun:true`）：占位（暂无卡），未来对兴奋剂和燃烧弹药有专属联动

## 📝 设计备忘

- 燃烧 = 可阻挡持续伤害（格挡对策）；**毒素**（未来）= 不可阻挡，另一体系
- 怪物不会上无法阻挡的掉血 buff
- 恢复**优先于**燃烧结算（避免带恢复被烫死）
- 免费打出的牌视为原本应有的消耗（战术突进/趁势追击/势不可挡/游击战术联动）
- **支援类吃易伤**（2026-08-11）：火力支援/女妖战机/燃烧轰炸/三连击延迟狙击的延迟伤害吃受击方易伤（×1.5），但仍只过格挡、不吃力量/虚弱；炸弹延迟伤害不吃易伤（维持原样）。STS2 mod 通过 `Entry.SupportDamage` 在 Unpowered 管线结算前手动应用易伤倍率实现
- 已知升级 63 条（`cards.json` known_upgrades）

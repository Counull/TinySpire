## 5. 维护规则

1. 角色身份锚点和三视图放 `agent-mythic-characters/turnaround-sheets/`。
2. 神话人物与 Agent 角色概念放 `agent-mythic-characters/concepts/`。
3. TinySpire 游戏角色和敌人概念放 `art-style/characters/`。
4. 全局风格锚点放 `art-style/anchors/`；场景放 `art-style/scenes/`。
5. 封面、Loading Screen、标题分别进入对应子目录，不堆在 `art-style/` 根目录。
6. `game-icons/` 只放真实图标用途素材，不放人物概念立绘。
7. 卡牌最终 UI 与拆分素材放 `cards/<card-id>/`。
8. 新增图片时，文件名应包含角色或用途、版本/变体、必要的修正版说明。
9. 新增、移动或重命名资源后，同步修改本文和所有引用旧路径的文档。
10. 本文只记录已存在的文件和可确认用途；助手建议不能自动升级为项目事实。
